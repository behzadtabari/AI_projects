# Image processing to perdict Numbers
Use MNIST to perdicate the number written on an Image

**Description**

You can for sure use your own testing dataset, otherwise find my handwritten numbers in data folder.

## Folder Structure

- [model](./model): model
- [data](./data): Data files

## Getting Started
To get a local copy up and running follow these simple steps.

### Prerequisites
- Python 3.x
- requirements.txt

### Installation
1. pip install -r requirements.txt
