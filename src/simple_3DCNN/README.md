# Simple Neural Network for Synthetic Data Classification

This repository contains a simple example of a neural network implemented using PyTorch for classifying synthetic 3D data. The model is designed with several 3D convolutional layers, followed by batch normalization and a fully connected layer, forming a compact yet effective structure suitable for small-scale synthetic datasets.

## Description

The codebase includes two main components:

1. **SimpleDataset**: A dataset class for generating and loading synthetic training and validation data.
   - The `SimpleDataset` class loads toy data generated by a helper function. This synthetic data is split into training and validation sets, facilitating quick experimentation without external data dependencies.

2. **SimpleModel**: A three-layer convolutional neural network (CNN) with batch normalization and ReLU activations.
   - The `SimpleModel` class stacks three convolutional layers followed by batch normalization. After the convolutional layers, a fully connected layer is applied to classify the 3D input data into two classes.

### Training Loop

The training loop is implemented in the `train` function. Key steps include:

- **Forward and Backward Passes**: The model performs forward and backward passes on batches of data, calculating loss using cross-entropy and adjusting weights using the Adam optimizer.
- **Validation**: During training, the model periodically evaluates on the validation set, tracking accuracy and saving the best model based on validation accuracy.

### Inputs

- **3D Input Data (input_data)**: The synthetic dataset contains 3D data in the shape `(batch_size, channels, depth, height, width)`.
- **Labels (target_labels)**: The class labels for each data sample.

### Output

The output is the class probabilities for each input sample after passing through the network. The model output has the shape `(batch_size, num_classes)`, representing the predicted class scores.
